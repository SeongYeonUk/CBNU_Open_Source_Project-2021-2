# CBNU Open Source Project 2021-2
## 환경·금융 데이터를 활용한 데이터 분석 프로젝트

충북대학교 컴퓨터공학과 **오픈소스프로젝트** 과목에서 수행한 데이터 분석 프로젝트입니다.

Python과 오픈소스 데이터 분석 라이브러리를 활용하여 서로 다른 출처의 실제 데이터를 정제·결합하고, 시각화 및 머신러닝 기법을 적용하여 변수 간 관계를 분석했습니다.

프로젝트는 처음 **대기오염 및 오염물질 배출시설과 질병·질환 간 관계를 분석하는 것**에서 시작했습니다. 그러나 실제 분석 결과 예상했던 것보다 변수의 설명력이 낮게 나타났고, 이를 계기로 동일한 데이터 분석 과정을 다른 분야에 적용해 보기 위해 **주가·금리·주택가격을 활용한 금융 데이터 분석**으로 범위를 확장했습니다.

이를 통해 단순히 원하는 결과를 얻는 것이 아니라, 실제 데이터에 기반해 가설을 검증하고 예상과 다른 결과가 나왔을 때 원인을 고민하며 새로운 분석 방향을 설정하는 과정을 경험했습니다.

---

## 1. Project Overview

### 분석 흐름

프로젝트는 다음과 같은 과정으로 진행했습니다.

```text
가설 설정
    ↓
실제 데이터 수집
    ↓
데이터 정제
    ↓
공통 기준 설정
    ↓
서로 다른 데이터셋 결합
    ↓
시각화를 통한 데이터 탐색
    ↓
머신러닝 모델 적용
    ↓
모델 성능 및 변수 관계 분석
    ↓
결과와 한계 해석
    ↓
새로운 데이터 영역으로 분석 확장
```

첫 번째 분석에서는 지역별 환경 데이터와 질환 데이터를 결합하여 대기오염과 질환 사이의 관계를 분석했습니다.

하지만 예상과 달리 선형회귀 모델의 설명력이 매우 낮게 나타났습니다.

이에 분석을 중단하거나 결과를 가설에 맞추기보다, 다른 성격의 실제 데이터에서는 어떤 결과가 나타나는지 확인하고 데이터와 변수 선택의 중요성을 학습하기 위해 **경제·금융 데이터로 분석 범위를 확장**했습니다.

두 번째 금융 데이터 분석에서는 첫 번째 환경 데이터 분석보다 상대적으로 높은 설명력을 확인할 수 있었습니다.

# 2. 환경 데이터 분석

## 2.1 분석 목적

처음에는 다음과 같은 가설을 설정했습니다.

> 대기오염 수준이 높거나 오염물질 배출시설이 많은 지역에서는 관련 질환 및 진료 지표 역시 높게 나타날 수 있을 것이다.

이를 확인하기 위해 지역별 환경 데이터와 질환 관련 데이터를 수집하여 하나의 데이터셋으로 결합했습니다.

---

## 2.2 활용 데이터

분석에는 다음과 같은 데이터를 활용했습니다.

- 대기오염물질 배출시설 데이터
- 미세먼지 관련 데이터
- 지역 및 주소 데이터
- 질환 및 진료 관련 데이터
- 지역별 인구 및 연령 관련 데이터

각 데이터는 서로 다른 형식과 기준으로 제공되고 있었기 때문에 분석에 앞서 데이터 전처리와 기준 통일이 필요했습니다.

---

## 2.3 데이터 전처리

주요 전처리 과정은 다음과 같습니다.

- 분석에 필요한 컬럼 선택
- 결측 데이터 제거
- 정상 영업 중인 사업장 데이터 필터링
- 주소 문자열을 시·도 및 시·군·구 단위로 분리
- 지역별 데이터 그룹화 및 집계
- 서로 다른 공공데이터를 지역 기준으로 결합
- 분석을 위한 데이터 정규화 및 형태 변환

`pandas`의 필터링, `groupby` 등의 기능을 이용하여 여러 데이터셋을 분석 가능한 형태로 정리했습니다.

특히 서로 다른 출처의 데이터를 그대로 결합할 수 없었기 때문에 **지역이라는 공통 기준을 만들어 여러 데이터셋을 연결하는 과정**에 중점을 두었습니다.

---

## 2.4 데이터 분석

전처리한 환경 데이터에 대해 다음과 같은 분석 및 머신러닝 기법을 실습·적용했습니다.

- 데이터 분포 시각화
- 변수 간 산점도 분석
- Linear Regression
- Ridge Regression
- Lasso Regression
- ElasticNet
- Logistic Regression
- PCA
- SVM
- K-Means

그중 미세먼지지수를 이용하여 진료실 인원수를 예측하는 단순 선형회귀 모델을 구성하고, 데이터를 Train/Test 데이터로 분리하여 모델을 평가했습니다.

---

## 2.5 환경 데이터 분석 결과

미세먼지지수를 이용해 진료실 인원수를 예측한 선형회귀 모델의 Test R²는 다음과 같이 나타났습니다.

```text
Test R² ≈ 0.050
```

설명력이 약 5% 수준으로 매우 낮았습니다.

즉, 초기 예상과 달리 **미세먼지 수준 하나만으로 질환 또는 진료 규모를 충분히 설명하기는 어렵다는 결과**를 확인했습니다.

이 결과를 통해 질환에는 대기오염 이외에도 다양한 요인이 복합적으로 영향을 미칠 수 있다고 판단했습니다.

예를 들어 다음과 같은 변수가 추가적으로 고려될 수 있습니다.

- 연령 및 인구구조
- 소득 수준
- 생활습관
- 의료 접근성
- 지역 특성
- 분석 시점
- 기타 환경 요인

또한 본 프로젝트에서는 엄밀한 통계적 유의성 검정을 수행한 것이 아니기 때문에 결과를 단순히 **"상관관계가 없다"**고 단정하기보다는,

> 현재 사용한 변수와 선형모델만으로는 질환 및 진료 지표에 대한 설명력이 낮았다.

라고 해석하는 것이 적절하다고 판단했습니다.

# 3. 금융 데이터 분석으로의 확장

환경 데이터 분석에서는 예상과 달리 높은 설명력을 얻지 못했습니다.

하지만 이러한 결과 역시 중요한 분석 결과라고 생각했습니다.

데이터 분석의 목적은 원하는 방향의 결과를 만드는 것이 아니라 **실제 데이터를 통해 가설을 검증하고 결과를 해석하는 것**이라고 판단했습니다.

이에 동일한 데이터 분석 과정을 성격이 다른 데이터에도 적용해 보기 위해 분석 대상을 경제·금융 데이터로 확장했습니다.

두 번째 분석에서는 서로 관계가 있을 것으로 예상되는 다음 세 가지 변수를 활용했습니다.

- 주가
- 금리
- 주택가격

---

# 4. 금융 데이터 전처리

## 4.1 서로 다른 시간 단위의 데이터

금융 데이터 분석에서 먼저 해결해야 했던 문제는 각 데이터의 시간 단위가 서로 다르다는 점이었습니다.

```text
주가       : 일별 데이터
금리       : 일별 데이터
주택가격   : 월별 데이터
```

따라서 데이터를 단순히 하나의 DataFrame으로 합치는 것이 불가능했습니다.

각 데이터가 동일한 시점을 기준으로 비교될 수 있도록 날짜 정보를 정리하고 시간 기준을 통일했습니다.

---

## 4.2 날짜 데이터 정제

일별 데이터의 날짜를 연·월 단위로 변환하여 월별 주택가격 데이터와 연결할 수 있도록 했습니다.

예를 들어 다음과 같이 날짜 기준을 변환했습니다.

```text
2021/08/06
    ↓
2021.08
```

이후 동일한 시점에 해당하는 데이터를 연결하여 다음과 같은 형태의 통합 데이터셋을 구성했습니다.

```text
날짜 | 금리 | 주가 | 주택가격
```

이를 통해 서로 다른 시간 단위로 제공되는 금융 데이터를 하나의 분석 데이터셋으로 통합했습니다.

---

## 4.3 자료구조 활용

월별 주택가격을 날짜와 대응시키는 과정에서는 **AVL Tree 기반 검색 구조**도 활용했습니다.

연·월 정보를 Key로 사용하여 해당 월의 주택가격을 검색하고 일별 금융 데이터에 연결했습니다.

이를 통해 자료구조에서 학습한 검색 개념을 실제 데이터 처리 과정에 적용해 보았습니다.

---

# 5. 금융 데이터 분석

## 5.1 주가와 금리 분석

먼저 주가를 독립변수, 금리를 종속변수로 설정하여 Linear Regression을 수행했습니다.

데이터를 Train/Test 데이터로 분리하여 모델을 평가한 결과 다음과 같은 성능을 확인했습니다.

```text
Test R² ≈ 0.405
```

환경 데이터 분석에서의 R² 약 `0.050`과 비교하면 상대적으로 높은 설명력을 확인할 수 있었습니다.

이를 통해 주가와 금리 사이에서 일정 수준의 선형관계가 나타날 수 있음을 확인했습니다.

다만 해당 결과만으로 주가가 금리를 결정한다고 판단할 수는 없으며, 변수 간 인과관계를 의미하지 않습니다.

---

## 5.2 주가·주택가격과 금리 분석

다음으로 주가뿐만 아니라 주택가격을 함께 독립변수로 활용하는 다중선형회귀 모델을 구성했습니다.

```text
주가
   \
    → Linear Regression → 금리
   /
주택가격
```

평가 결과는 다음과 같았습니다.

```text
Test R² ≈ 0.488
```

주가만 활용했을 때의 약 `0.405`에서 주택가격을 함께 활용했을 때 약 `0.488`로 모델의 설명력이 증가했습니다.

이를 통해 **관련 변수를 추가하고 어떤 변수를 선택하느냐에 따라 모델의 설명력이 달라질 수 있다는 점**을 확인했습니다.

또한 환경 데이터 분석과 비교했을 때 주가·금리·주택가격 데이터에서는 상대적으로 더 뚜렷한 선형관계가 나타났습니다.

다만 실제 금리 및 금융시장에는 다음과 같은 다양한 요소가 복합적으로 영향을 미칠 수 있습니다.

- 기준금리 및 통화정책
- 물가
- 경제성장률
- 통화량
- 환율
- 시장 심리
- 국내외 경제 상황

따라서 본 프로젝트에서는 인과관계를 주장하기보다 **선택한 데이터에서 나타나는 변수 간 관계를 탐색하는 수준**으로 결과를 해석했습니다.

# 6. 두 분석 결과 비교

두 데이터 분석의 대표적인 Linear Regression 결과를 비교하면 다음과 같습니다.

| 분석 | 입력 변수 | 예측 대상 | Test R² |
| --- | --- | --- | ---: |
| 환경 데이터 | 미세먼지지수 | 진료실 인원수 | 약 0.050 |
| 금융 데이터 | 주가 | 금리 | 약 0.405 |
| 금융 데이터 | 주가 + 주택가격 | 금리 | 약 0.488 |

환경 데이터에서는 예상했던 것보다 매우 낮은 설명력이 나타났습니다.

반면 금융 데이터에서는 상대적으로 높은 설명력이 나타났으며, 주가만 활용했을 때보다 주택가격을 함께 활용했을 때 R²가 증가했습니다.

이를 통해 **분석 결과는 사전에 세운 가설과 다를 수 있으며, 데이터의 특성과 변수 선정에 따라 모델의 설명력이 크게 달라질 수 있다는 점**을 경험했습니다.

# 8. 프로젝트를 통해 배운 점

## 8.1 실제 데이터 분석에서는 전처리가 중요하다

프로젝트를 수행하면서 머신러닝 알고리즘을 적용하는 과정 못지않게 실제 데이터를 분석 가능한 형태로 만드는 과정이 중요하다는 점을 경험했습니다.

환경 데이터에서는 서로 다른 데이터들을 **지역**이라는 기준으로 연결했고, 금융 데이터에서는 일별 데이터와 월별 데이터를 **날짜**라는 기준으로 연결했습니다.

이를 통해 실제 데이터 분석에서는 데이터의 형식과 기준을 통일하고 정합성을 확보하는 과정이 중요하다는 점을 배웠습니다.

---

## 8.2 예상과 다른 결과도 의미 있는 결과이다

처음에는 대기오염 수준과 질환 지표 사이에서 비교적 뚜렷한 관계가 나타날 것으로 예상했습니다.

그러나 실제 분석에서는 Test R²가 약 `0.050`으로 매우 낮게 나타났습니다.

결과를 가설에 맞추기보다 해당 결과 자체를 받아들이고, 왜 설명력이 낮게 나타났는지 추가 변수와 분석 방법의 한계를 고민했습니다.

이를 통해 데이터 분석은 원하는 결과를 찾는 과정이 아니라 **데이터를 기반으로 가설을 검증하고 결과를 해석하는 과정**이라는 점을 배웠습니다.

---

## 8.3 분석 결과를 바탕으로 새로운 분석 방향을 설정했다

환경 데이터에서 낮은 설명력을 확인한 이후 분석을 중단하지 않고, 같은 분석 방법을 다른 성격의 데이터에 적용해 보기 위해 금융 데이터 분석으로 범위를 확장했습니다.

금융 데이터에서는 R²가 약 `0.405~0.488`로 상대적으로 높게 나타났고, 데이터 및 변수의 특성에 따라 모델의 설명력이 크게 달라질 수 있음을 확인했습니다.

---

## 8.4 변수 선정의 중요성을 확인했다

금융 데이터에서는 주가만 사용했을 때보다 주택가격을 함께 사용했을 때 모델의 설명력이 증가했습니다.

이를 통해 어떤 변수를 선택하고 결합하는지가 분석 결과에 영향을 줄 수 있다는 점을 확인했습니다.

---

## 8.5 자료구조와 데이터 분석을 연결했다

금융 데이터를 결합하는 과정에서는 AVL Tree 기반 검색 방식을 활용했습니다.

이를 통해 자료구조 과목에서 학습한 검색 개념이 단순한 알고리즘 문제 풀이를 넘어 실제 데이터 처리에도 활용될 수 있다는 점을 경험했습니다.

# 9. Limitations

본 프로젝트는 2021년 학부 오픈소스프로젝트 과목에서 실제 데이터 분석과 오픈소스 라이브러리 활용을 경험하기 위해 수행한 프로젝트입니다.

따라서 다음과 같은 한계가 있습니다.

- 변수 간 관계가 인과관계를 의미하지 않음
- 환경 데이터의 지역 및 시점 기준이 완벽하게 일치하지 않을 수 있음
- 질환에 영향을 줄 수 있는 연령, 소득, 생활습관, 의료 접근성 등의 변수가 충분히 포함되지 않음
- 금융시장에 영향을 미치는 물가, 통화량, 환율, 경기지표 등이 충분히 포함되지 않음
- 시계열 데이터에 일반적인 Train/Test random split을 적용하여 시간 순서를 충분히 고려하지 못함
- 모델별 하이퍼파라미터 최적화가 충분하지 않음
- 엄밀한 통계적 유의성 검정이나 인과관계 분석까지 수행하지는 않음

현재 다시 분석한다면 다음과 같은 방법을 추가할 수 있습니다.

- 시계열 기반 Train/Test 분리
- 추가 변수 확보
- Feature Engineering
- Cross Validation
- 하이퍼파라미터 튜닝
- 변수 간 상관분석 및 통계적 유의성 검정
- 시계열 회귀 및 예측 모델 활용

# 11. Summary

본 프로젝트에서는 여러 출처에서 제공되는 실제 데이터를 정제하고 공통 기준으로 결합한 뒤, 다양한 데이터 분석 및 머신러닝 기법을 적용했습니다.

처음에는 대기오염 및 오염물질 배출시설과 질환 사이의 관계를 분석했습니다. 그러나 미세먼지지수를 이용해 진료 관련 지표를 설명한 선형회귀 모델의 Test R²는 약 `0.050`으로 예상보다 낮았습니다.

이를 단순한 실패로 판단하지 않고, 데이터와 변수의 특성에 따라 분석 결과가 어떻게 달라지는지 추가로 확인하기 위해 분석 대상을 금융 데이터로 확장했습니다.

주가·금리·주택가격 데이터를 날짜 기준으로 정제하고 통합하여 분석한 결과, 주가를 이용해 금리를 설명한 모델에서는 약 `0.405`, 주가와 주택가격을 함께 활용한 모델에서는 약 `0.488`의 Test R²를 확인했습니다.

이를 통해 하나의 분석 과정 안에서 다음과 같은 전체 데이터 분석 프로세스를 경험했습니다.

```text
가설 설정
    ↓
데이터 수집
    ↓
데이터 전처리
    ↓
데이터 통합
    ↓
탐색 및 시각화
    ↓
모델 적용
    ↓
모델 평가
    ↓
결과 및 한계 해석
    ↓
새로운 분석 방향 설정
```

특히 원하는 결과에 맞추기보다 **실제 데이터가 보여주는 결과를 받아들이고, 예상과 다른 결과가 나왔을 때 그 원인과 한계를 분석하여 다음 분석 방향을 설정하는 것이 데이터 기반 문제해결에서 중요하다**는 점을 배웠습니다.
